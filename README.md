# Crocword (OpenCrocword)

Мобильный клон Crocword на чистом HTML/CSS/JS. Без фреймворков и сборки.
Уровни и словари лежат в JSON, сохранение — в `localStorage`.

## Запуск

Игра использует ES-модули и `fetch`, поэтому нужен HTTP-сервер:

```powershell
cd D:\Games\OpenCrocword
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

Открыть <http://127.0.0.1:8080/>. Порт можно изменить: `-Port 8090`.

## Что уже работает

- Эпизод 1 «Джунгли»: 15 уровней, экран эпизода 3×5.
- Уровни открываются последовательно: следующий доступен после прохождения предыдущего.
- Уровни 6 и 15 помечены короной (пока только визуально).
- Сетка кроссворда: слова открываются целиком, буквы скрыты до отгадывания.
- Колесо букв: ввод свайпом или перетаскиванием, линии между выбранными буквами.
- Плашка над колесом показывает набираемое слово.
- Найденное слово: буквы по очереди перелетают из колеса в ячейки сетки.
- Неверное слово: плашка встряхивается и подсвечивается красным, короткая вибрация (если поддерживается).
- Кнопка перемешивания букв (бесплатно, без кулдауна).
- Ключевое слово уровня: начисляет 100 монет, в сетку не записывается.
- Бонусные слова: 3–8 на уровень, каждое даёт +10 монет, повторно не начисляются.
- Подсказка: открывает случайную закрытую букву неразгаданного слова за 25 монет.
- Монетные ячейки: 1–3 на уровень (золотая точка в углу), +10 / +20 / +30 монет
  при открытии слова. Начисляются один раз.
- Копилка: 10% каждого заработка копится отдельно, забирается вручную на экране эпизода.
- Завершение уровня: ввод блокируется сразу после последнего слова, появляется оверлей
  с Профессором Кроком (заглушка), конфетти и наградой. Кнопки «Продолжить» (следующий
  уровень) и «В меню» (экран эпизода).
- Сохранение прогресса, монет и текущего уровня между запусками.
- Переключение уровня через экран эпизода.
- Темы оформления: `jungle` (эпизод 1), `normal`, `hard` (заложены в коде).

## Экономика

| Действие | Монеты |
|---|---|
| Первое прохождение уровня | +40 + 12 × (слов в сетке) + 4 × min(уровень, 15) |
| Ключевое слово | +100 |
| Бонусное слово | +10 |
| Монетная ячейка | +10 / +20 / +30 |
| Подсказка | −25 |
| Копилка | 10% от каждого заработка |

Пример: уровень 1, 5 слов → 104 монеты игроку и 10 в копилку; уровень 2 → 108 и 11.
Повторное прохождение в текущей версии не награждается (25% заложены в константах).
Монетные ячейки и копилка начисляются один раз: факт хранится в `claimedCoins`.

Монеты не продаются и не выдаются за рекламу. Рекламных SDK в проекте нет.

## Сохранение

Ключ: `localStorage['crocword_save']`.

```json
{
  "version": 3,
  "coins": 500,
  "bank": 0,
  "level": 1,
  "progress": {
    "1": {
      "found": [],
      "bonus": [],
      "hinted": [],
      "claimedCoins": [],
      "keyFound": false,
      "completed": false,
      "bankRewarded": false
    }
  }
}
```

Старые сохранения мигрируют автоматически (`js/core/storage.js`): `bank` появился
в версии 3, `claimedCoins` хранит забранные монетные ячейки.

## Генерация уровней

```powershell
node tools/gen-levels.mjs
```

Скрипт детерминирован: при одинаковом словаре и seed результат совпадает.
Генерирует `levels.json`, проверяет каждый уровень валидатором:

- все слова есть в словаре;
- все слова собираются из букв ключевого слова;
- нет конфликтов букв и отрицательных координат;
- нет двухбуквенных склеек: каждый ряд на доске — объявленное слово;
- каждое слово после первого пересекается с сеткой;
- бонусных слов 3–8, все есть в словаре и собираются из букв ключевого слова;
- монетные ячейки лежат внутри сетки, не дублируются, значение 10/20/30.

Бонусные слова подбираются из словаря по буквам ключевого слова: сначала более
длинные, затем короткие, без повторов и без слов из сетки.

Монетные ячейки расставляются детерминированно: 1 ячейка на уровнях 1–5 (×10),
2 на 6–10 (×20), 3 на 11–15 (×30), приоритет — пересечения слов.

`tools/gen-levels.mjs` также можно импортировать в браузере: функции
`generateEpisode`, `generateLevel`, `validateLevel` не зависят от Node.

## Статус PWA

`manifest.json`, `sw.js` и иконки пока не подключены к `index.html`.
Офлайн-режим и установка на телефон не работают. Это отдельный этап.
