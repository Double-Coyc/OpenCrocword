# OpenCrocword 🎮

Красивая словесная игра в стиле Crocword с поддержкой PWA (Progressive Web App). Полностью без рекламы, с офлайн-режимом и возможностью установки на смартфон.

## 🌟 Особенности

- **PWA поддержка**: Работает офлайн, устанавливается на домашний экран смартфона
- **Без рекламы**: Никакой навязчивой рекламы
- **25 уровней**: От простых до сложных кроссвордов
- **Touch поддержка**: Оптимизирована для сенсорных экранов
- **Сохранение прогресса**: Автосохранение в localStorage
- **Монеты и награды**: Система монет без рекламы
- **Подсказки**: Помощь в сложных ситуациях
- **Красивый дизайн**: Современный интерфейс с анимациями

## 🎯 Как играть

1. **Сверху** - сетка кроссворда
2. **Снизу** - колесо с буквами
3. **Выбирайте** буквы и перетаскивайте их в сетку
4. **Создавайте** слова из букв
5. **Используйте** подсказки, если застряли
6. **Зарабатывайте** монеты и открывайте новые уровни

## 📱 Установка на смартфон

### На Android:
1. Откройте игру в Chrome
2. Нажмите на иконку меню (три точки) в адресной строке
3. Выберите "Установить приложение"
4. Подтвердите установку

### На iPhone/iPad:
1. Откройте игру в Safari
2. Нажмите на иконку "Поделиться" (стрелка вверх)
3. Прокрутите вниз и выберите "На экран "Домой""
4. Нажмите "Добавить"

## 🎮 Управление

- **Свайп мышью или пальцем**: Выбор букв и заполнение сетки
- **Кнопка "Подсказка"**: Открывает случайную букву (-25 монет)
- **Кнопка "Бесплатные монеты"**: +50 монет с кулдауном 10 секунд
- **Кнопка "Перемешать"**: Перемешивает неиспользованные буквы
- **Кнопка "Очистить"**: Очищает сетку от незаполненных букв
- **Кнопка "Проверить"**: Проверяет текущее слово

## 🏆 Система монет

- Начальное количество: 100 монет
- За каждый уровень: 50-1200 монет (в зависимости от сложности)
- Подсказка: -25 монет
- Бесплатные монеты: +50 монет (10 секунд кулдаун)
- Удвоение награды: мгновенное удвоение монет за уровень

## 🛠️ Технические детали

- **PWA**: Service Worker для офлайн-режима
- **Сохранение**: localStorage для прогресса и настроек
- **Звуки**: Web Audio API для звуковых эффектов
- **Адаптивный дизайн**: Mobile-first подход
- **Кроссбраузерность**: Поддержка всех современных браузеров

## 🚀 Запуск

Просто откройте файл `index.html` в любом современном браузере. Игра готова к использованию!

## 🎨 Разработка

Игра написана на чистом HTML, CSS и JavaScript без использования фреймворков. Для создания иконок использован Python с библиотеками zlib и struct.
